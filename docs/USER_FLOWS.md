# تدفقات المستخدم (User Flows)

## 1. مشرف (Admin)

```mermaid
flowchart TD
  A[زيارة الموقع] --> B{مسجّل دخول؟}
  B -->|لا| C[/login]
  C --> D[لوحة /admin]
  B -->|نعم| D
  D --> E[الطلاب: إضافة/تعديل/حذف]
  D --> F[الحضور: اختيار تاريخ وتسجيل]
  D --> G[الحفظ: إضافة سجل]
  D --> H[المالية: فاتورة/دفعة]
  D --> I[التقارير: ملخص]
  D --> J[تسجيل خروج]
```

## 2. طالب (Student)

- تسجيل الدخول → `/student` (ملخص قابل للتوسع لاحقًا بالجدول والحضور).

## 3. ولي أمر (Parent)

- تسجيل الدخول → `/parent` (ملخص الأبناء لاحقًا بعد ربط الحساب).

## 4. أول تشغيل (مطوّر / مالك)

1. إعداد `.env` من `.env.example`.
2. `npm run db:prepare` (قاعدة + جداول + seed مشرف).
3. `npm run dev` → دخول بـ `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
