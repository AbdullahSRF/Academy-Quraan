# خارطة الميزات (Features Map)

## MVP — النسخة الأولى

| الميزة | الوصف | الحالة |
|--------|--------|--------|
| **Authentication** | تسجيل دخول بيانات (Auth.js) + أدوار | جاهز |
| **Dashboard** | لوحة لكل دور + تنقل جانبي للمشرف | جاهز |
| **إدارة الطلاب** | قائمة، إضافة، تعديل، حذف، بيانات أساسية | MVP وظيفي (`/admin/students`) |
| **الحضور والغياب** | تسجيل لكل طالب + تاريخ + عرض يوم | MVP (`/admin/attendance`) |
| **الحفظ والتسميع** | إضافة سجل + قائمة أحدث السجلات | MVP (`/admin/memorization`) |
| **المالية** | إصدار فاتورة + قائمة فواتير | MVP (`/admin/finance`) — الدفعات لاحقًا |
| **التقارير** | أرقام مجمّعة + حسب حالة الطالب | MVP (`/admin/reports`) |
| **PWA** | تثبيت وتحسين تحميل | مفعّل في الإنتاء |
| **Auto-save** | debounce للحقول الطويلة | خطاف `useAutoSave` — ربط بنماذج المذكرة لاحقًا |
| **Daily Backup** | `npm run backup` (مع `.env`) + `pg_dump` | موثّق في `docs/OPERATIONS.md` |

## ما بعد MVP

- **نظام الحفظ الذكي (مناطق NEW / NEAR / FAR + جلسات + محرك تلقائي):** مُوثَّق في [`MEMORIZATION_SYSTEM.md`](./MEMORIZATION_SYSTEM.md) — التنفيذ البرمجي والواجهات لاحقًا.
- تصدير CSV/PDF للتقارير.
- إشعارات (بريد / واتساب) — تكامل خارجي.
- لوحة ولي الأمر: ربط تلقائي بالطلاب بدعوات.
- صلاحيات دقيقة داخل دور المشرف.
- فواتير دورية واشتراكات.
